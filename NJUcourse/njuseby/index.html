# 从预推免考核本身讲起

# 项目

今年最大的改革就是取消笔试，新增了一个项目，要求你在一周时间内完成，允许并鼓励使用 ai 工具辅助开发，主题是一个编程 agent，形式不限、可简单可复杂、唯一的要求是不允许用框架。孩子们，我认为这个项目本质上就是在比谁 token 多啊，更粗暴点就是比谁有钱啊。或许 jyy 说的是对的，没有 token 的学生不能保研南京大学软件学院！

我做的是一个带 canvas 看板的 web 式编程 agent，可以在 canvas 上贴标签给标签连线，就像思维导图一样，然后传给 ai；ai 也可以生成 canvas 看板，目的是让用户和 ai 之间可以有更多的交流方式与交流空间。有个创新点我觉得还是不错的，面试老师当时也围绕 canvas 问了我几个问题。你想，一个老师一场下来面试几十个学生，必须得拿出点什么东西能让他眼前一亮才行啊（即便是没啥用的噱头，哈哈，但是想法是好的就没问题，你只要能说服面试老师就行）。

# 面试

面试形式双盲，禁止在面试过程中透露出任何个人信息，并且需要提前到等候教室等待且不允许携带任何电子产品进入等候室。对，你等的时候没法玩手机，只能打印点资料或者带书进去看，如果你很倒霉是这一组最后几个面试的话，得在里面干坐四五个小时。（至于为什么是这个有些反人类的设计，当时有个老师来我们教室解释说，之前是可以带手机的，但是有个人没有保上南软，就向教育部举报南软面试等待时可以带手机，可能会出现前面的人面完后透题给后面的人，给南软带来不少麻烦。前人砍树，后人暴晒啊。）

流程上，首先是播放项目视频，限时两分钟，你之前剪好了和项目链接一起传上去的东西。我当时放的时候面试老师还让我根据视频实时讲解内容。

接着，一分钟的英文介绍，介绍你之前做的项目。这个环节老师会计时所以得把握好时间，理论上也是面试中唯一考核英文的环节（but，我听说有的面试教室老师后面问问题也会要求用英文回答？？？我当时是没遇到的。）

老师可能会围绕你的项目问你一些问题，也可能直接进入抽题环节，抽一到两条 agent 相关题目（从题库抽取）。搞笑的地方来了，明明之前发布项目的时候，文件里写的是 “功能繁简不限，可以很简单也可以很完善”，但是抽的问题里有很多都是围绕 “你的 agent 遇到 xxx 情况怎么处理”，比如 agent 遇到危险指令，遇到提示词注入，遇到把代码改错，等等。从我个人了解到的问过的问题来看，很大一部分重心是放在安全性相关问题上，如果你的 agent 没做或者没深入做相关功能就很吃亏。

然后是抽取两道（或者更多）专业题（也是从题库抽），不会的话可以换题，你答的不好的话老师也会换题。范围很广，宏观上的软质软统，具体点的读代码讲输出、现场 debug，等等等等，都有可能出现。这个没什么好讲的，范围太大了。然后抽一道思政题，这个回答只要正能量就可以了。

问答结束后老师会问你有没有什么比赛或者科研或者项目（他不一定直接这么问，像我当时面试老师就问 “有没有什么骄傲的东西”），这个你按实际情况回答就行。似乎老师们都对大创经历比较感兴趣，有的可能还会深入问，不过前提是这个大创得含金量高，如果是校级的也没用。

然后没了！

# 机试

今年是四小时五道题，具体题目是什么这里就不说了可以自行到 xhs 上搜索。我只能说，非常难，我只有 260 分，我是区。

但是其实今年占比上是机试 50 分，面试 100 分，所以你机试考的很高也有可能被面试打飞，机试考的不好被面试拯救。

此外今年考试系统是经过 lbd 改版后的定制版 dotoj，最大的特性就是有公开样例和隐藏测试用例，且你提交上去后看不见你的代码在隐藏测试用例上拿了多少分。这就会导致你的代码可能明明公开用例都过了，你当着它是满分，但是实际上并没有。之前我们私底下讨论过为什么要设置成这种形式，难道是想着私下调整分数捞一捞本院学生？但是根据我后面了解好像根本就没有手动调分，就是单纯地加了隐藏用例隐藏测试。

没有什么好说的了，每年机试题目、机试形式都不一样（包括面试），也没人知道明年会是什么样子。不过我还是要说早八考试好变态考四个小时更是变态，其实是在考马拉松有感觉吗，筛选出身体好的优秀人才，为将来进入大厂猛猛加班做准备。

# 那么，我可以为预推免准备什么？

我其实没咋准备，当时在 mhy 实习，在预推免考试前请了一周的假回学校复习，也就只是稍微刷了刷力扣把写题目的手感找了回来，然后很随便地看了几眼专业知识点（约等于没看）。机试，我认为你复习再多准备再多也不可能做出来第五道题，那道题感觉是考数学甚至考智商了，前面的题也很有难度反正我第三题就不会做；而面试，考察范围太大，复习的话感觉是大海捞针。不过也还是有些高频考点的，比如设计模式。对于 agent 的话，我前面也提到了问的很多都是安全性问题，了解自己 agent 相关方面的实现即可。不过明年还有没有这个 agent 我就不知道了。

换句话说，我认为对南软预推免针对性复习基本上是一件不可能的事情，如果要针对的话那这根针也太粗了！这更像是一种 “厚积而薄发”，但是吧仔细想想也不对，毕竟靠面试抽了几条题目来评判你这个人水平究竟如何随机性也太大了，老师们的评分也不一定有统一的标准，面试似乎是这个世界上最主观的东西了。

所以到底能准备什么？哼哼，老实说我也不知道。我最大的建议或许是放平心态 —— 如果你是本院学生的话。如果是外院或者外校，最起码我没有一个 100％你按照我说的做就能提升保南软成功率的方法。

“功夫在平时”—— 这句话或许是对的。反正，我认为你得在考试之前把做题的手感找回来，内心给自己打气而不是垂头丧气，以及睡一个好觉，养精蓄锐。

# 本院同学最关心的事情：今年究竟有没有 “保底”

实话实说，可能是没有的，但是软院整体情况平心而论比外面明确没有保底甚至 “否定自己的本科教育” 的院要好一些。我身边的朋友有准出资格的，最后都有了自己的归属。

但是，我们不能排除明年情况继续恶化的可能性，最起码今年的情况比去年坏的多。已知有没有获得本院优营最后只能考工程硕博的，也有明明机试排名很高但面试非常之拉胯疑似一点没捞总排名甩到 140 + 的（不过这位同学最后候补上了，南软鸽子多）。今年所谓的本校保护，可能确实是消失了罢。

那么本院同学究竟还有没有优势，会不会被外校同学薄纱？机试的话，大概也就只有你用过 dotoj 知道 dotoj 得自己写输入输出，自定测试怎么使用；而面试是双盲，你顶多就是看见面试题里有一些经典软工知识你感觉很熟悉，或者看见自己熟悉的老师所以没那么紧张。虽说本院内部可以提前获取到一些消息，但是对于考核本身的帮助是很有限的，我也不清楚今年软院内部究竟有没有做一些内部调分来保护同学们（我猜大概是没有的）。唉唉，不会南京大学软件学院也要否定自己的本科教育吧（虽然他确实应该否定）！

对于后面的同学们，我的建议是…… 呃，没有建议。南软还不至于斩杀本院学生，外校同学也不一定那么强大，还是可以相信一下自己的能力的。至于最后结果究竟如何，比起看学院，还是看你们自己喽！

# 额外附赠：关于今年南软准出的情况

如果有谁看见外面在宣传南软今年（23 级）保研率来到了 50%，那我真的是无语 + 笑到吐。你们怎么好意思宣传的？

讲一下今年具体的数据，年级共 226 人，准出名额是 93 人，93/226=41%，这个数字看起来还行。那么为什么一直顺延到 50%，足足有二十几个人放弃？我分析了一下汇总表，绩点排名 115 有三个人放弃，1684 有三个人放弃，这边总共放弃六个人，不排除有一半多都是出国；真正开始放弃多的是从 85 名开始，85/226=37%，刚好是去年 22 级的保研线附近。也就是说，有很多保研线附近的同学可能已经找到了工作 or 意向是就业，所以放弃了保研。于是一直到排名 116 名也是最后一位保研的同学，中间大多数人选择了放弃，才导致顺延到了 50% 向后。

那么到这里，我要讲一个笑话了。这次准出名单的最后两名都是我比较好的朋友，而他们当初报名南软预推免（准入）的时候，全都没有入营 —— 因为他们绩点排在后 50%，而南软这次本院入营卡死前 50%，要知道往年都是前 70%！我还要讲一个前置的笑话，当初关于预推免开会的时候，老师说，“让每一个有准出名额的同学都有书读”，这句话听起来挺安心的是吧？事实上你们知道这句话是什么意思吗，还记得前面我讲了一个因为面试拉胯导致总排名靠后的同学吗，后来老师给他打电话，意思是让他尽快找别的准入保底，“如果没有准入那就是在浪费名额，对别的同学不公平”。呵呵哒孩子们你们能理解了吗，不是你有准出南软就一定保你，而是如果你没准入南软就不想让你准出。

然后这边还有个工程硕博的存在，要知道如果考了工程硕博然后通过，是会直接覆盖掉你本院的准入的（相当于锁档，候补也没法候补上）。当时辅导员私下联系了很多在候补的人让他们去考这个，现在想想，某种意义上也是在坑人啊（毕竟今年南软鸽子多，候补很有机会）。

所以南软的回旋镖来了，如果我那两个朋友也放弃了准出资格，再向后顺延，那后面的人更没有准入，那还不知道得顺延到哪里去呢！南软一开始告诫学生 “不要浪费资格”，结果最后是他们拿起石头砸自己的脚，自己浪费自己的资格啊！不过幸运的是，我那两位朋友一个最后保去了北航，还有一个打智软复活赛成功打赢，大家最后都有书可读了。
