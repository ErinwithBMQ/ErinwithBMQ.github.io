# 我笔下的他们

比起说分析荒诞的现实，然后得出可能不够准确的结论，在此之前，我想写一下我笔下他们的模样。

我喜欢平等的关系，喜欢纯爱，喜欢简单又纯粹的感情。所以，我的所有创作中对于他们本人的性格定位似乎都基于我的喜好做出了侧重。甚至，因为我的喜好，我对他们的分析与理解也都会往这个方向偏。

其实我总是觉得我写的他们和现实中的那俩并不是同一个人。我写崔然竣是一个有些脆弱的人，写崔杋圭是一个有坚定内心的人，写崔然竣是一个渴望爱的人，写崔杋圭是一个提供爱的人。这是互补吗？是互补。但是，这是相似吗？这也是相似。

所有的动机都来源于个人的内核。底色同样是温柔的二人走上的是相似又相反的道路。根是相似的，道路是相反的，这是一个迷人的纠缠，与此同时也说明了，为何他们可以互相理解，又可以互相提供。

我笔下的杋圭，温柔的灵魂选择的是以自我为基向他人提供力量的道路。我笔下的然竣，温柔的灵魂选择的是隐去自我只为你点亮明灯的道路。

这么一想，其实我对然竣还挺不公平的，其实我后面非常想尝试以他为叙事主体的文章，因为无论是《缄默誓言》还是《梦醒记》注重的似乎都是杋圭的成长。这其实和现实是息息相关了，毕竟我目前是看见了崔杋圭身上的闪光点，而对崔然竣身上潜在的危机感到担忧。不过 “不公平” 不代表我不爱他，如果我真的不爱，就不会写他的脆弱。

或许这也是我喜欢平等的原因吧。我将可能在感情中处于低位的杋圭往上抬，将可能处于高位的然竣往下压。然而真的是这样吗？我觉得我写的没有问题，他俩本就如此，在外层的关系上是哥哥托住弟弟，而在内层的关系上，我认为其实就是杋圭在托住然竣。

好吧，这只是我写后记写累了随便写了点别的。说实在的这种关系真的是在我的 xp 上，大家再味一味缄默誓言就知道这篇完全就是这样。至于为什么我会这么认为，那还得大家读了后记才知道一切的答案。

不过其实写这个后记已经让我感到乏味了，是那种把一切事情都从个人的角度想通后，再看现实的乏味。
